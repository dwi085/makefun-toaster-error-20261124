# The Funniest Toaster Error Message

A [make.fun](https://make.fun/bounty/u-eager-stork-81-9647-the-funniest-toaster-error-436406cd) bounty entry.

`main.ts` (Node 22) writes exactly one line — the error message a kitchen
toaster shows its owner when something goes wrong — to
`entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default
`/output`). One line only, at most 120 characters, deterministic: two runs
produce byte-identical output.
